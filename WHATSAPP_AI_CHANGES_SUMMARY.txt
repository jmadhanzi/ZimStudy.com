✅ Usage statistics and message history tracking

DEPENDENCIES ADDED:
------------------
- openai (^4.x) - OpenAI API client
- node-cron (^3.x) - Task scheduling

CONFIGURATION REQUIRED:
----------------------
Environment variables needed in backend/.env:
- TWILIO_ACCOUNT_SID
- TWILIO_AUTH_TOKEN
- TWILIO_WHATSAPP_NUMBER
- WHATSAPP_VERIFY_TOKEN
- OPENAI_API_KEY

SCHEDULED TASKS:
---------------
- Daily Quiz: 9:00 AM (every day)
- Study Reminder: 6:00 PM (every day)
- Motivational Messages: 7:00 AM (Mon/Wed/Fri)
- Weekly Progress: 10:00 AM (Sunday)

API ENDPOINTS ADDED:
-------------------
GET  /api/whatsapp/history                - Get message history
GET  /api/whatsapp/stats                  - Get usage statistics (admin)
POST /api/whatsapp/test/daily-quiz        - Trigger daily quiz (admin)
POST /api/whatsapp/test/study-reminder    - Trigger study reminder (admin)
POST /api/whatsapp/test/progress-update   - Trigger progress update (admin)
